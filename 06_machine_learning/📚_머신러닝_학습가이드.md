## 📊 1. 데이터 전처리 (Data Preprocessing)

### ⭐ 핵심 개념
**"Garbage In, Garbage Out"** - 좋은 데이터가 좋은 모델을 만듭니다!

### 🔥 실전에서 가장 중요한 내용

#### 1️⃣ **결측치(Missing Value) 처리** ⚠️ 최우선 작업
```python
# 결측치 확인 (필수!)
df.isna().sum()

# 처리 방법 선택
df.dropna()              # 삭제 (데이터가 충분할 때)
df.fillna(df.mean())     # 평균값으로 대체
df.fillna(df.median())   # 중앙값으로 대체 (outlier 있을 때 권장)
df.fillna(df.mode()[0])  # 최빈값으로 대체 (범주형)
```

**💡 실전 팁:**
- **outlier가 있으면 평균 대신 중앙값 사용!**
- 범주형 데이터는 최빈값 사용
- KNN Imputer 활용 (sklearn 제공)

#### 2️⃣ **Feature Scaling** 🎯 성능 향상의 핵심

**왜 필요한가?**
- 거리 기반 알고리즘 (KNN, SVM, 신경망)에서 필수!
- 나이(0-100)와 연봉(2000만-1억)의 스케일 차이 때문

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# StandardScaler (가장 많이 사용!) - 평균 0, 표준편차 1
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)  # ⚠️ fit은 train만!

# MinMaxScaler - 0~1 범위로 변환
scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X_train)
```

**⚠️ 주의사항:**
1. **Train set으로 fit() 후 Test set은 transform()만!**
2. **Scaling 전후 데이터 분포 시각화 확인!**
3. Tree 계열 모델(DecisionTree, RandomForest)은 Scaling 불필요

#### 3️⃣ **범주형 데이터 인코딩** 🔤→🔢

```python
from sklearn.preprocessing import LabelEncoder, OneHotEncoder

# LabelEncoder - 순서형 데이터 (학년: 1학년, 2학년, 3학년)
le = LabelEncoder()
df['grade_encoded'] = le.fit_transform(df['grade'])

# OneHotEncoder - 명목형 데이터 (혈액형: A, B, O, AB)
# ⭐ 실전 필수! 가장 많이 사용
ohe = OneHotEncoder()
encoded = ohe.fit_transform(df[['blood_type']])

# 또는 pandas 활용
df_encoded = pd.get_dummies(df, columns=['blood_type'])
```

**💡 선택 기준:**
- **순서가 있으면** → LabelEncoder
- **순서가 없으면** → OneHotEncoder (대부분의 경우)

## 🔍 3. 분류(Classification) 평가지표

### ⭐ 이진 분류 핵심 개념

```
양성(Positive) = 찾으려는 대상 (1)
음성(Negative) = 나머지 (0)

예시:
- 스팸메일 분류 → Positive: 스팸, Negative: 정상메일
- 암환자 진단 → Positive: 암환자, Negative: 정상
```

### 📊 Confusion Matrix (혼동 행렬) - 기본 중의 기본!

```
                예측값
           Negative  Positive
실제값  
Negative     TN        FP
Positive     FN        TP
```

- **TP** (True Positive): 양성을 양성으로 ✅
- **TN** (True Negative): 음성을 음성으로 ✅
- **FP** (False Positive): 음성을 양성으로 ❌ (1종 오류)
- **FN** (False Negative): 양성을 음성으로 ❌ (2종 오류)

### 🔥 핵심 평가지표 (실전 필수!)

#### 1️⃣ **Accuracy (정확도)** - 기본 지표
```python
from sklearn.metrics import accuracy_score
accuracy = accuracy_score(y_true, y_pred)
```
- 전체 중 맞게 예측한 비율
- **⚠️ 불균형 데이터에서는 부적절!**
  - 예: 암환자 1%, 정상 99% → 모두 정상이라 해도 99% 정확도!

#### 2️⃣ **Precision (정밀도)** - "양성 예측의 신뢰도"
```python
from sklearn.metrics import precision_score
precision = precision_score(y_true, y_pred)
```
$$Precision = \frac{TP}{TP + FP}$$

- **양성으로 예측한 것 중 실제 양성인 비율**
- **언제 중요?** → FP를 줄여야 할 때
  - 스팸메일 필터: 정상 메일을 스팸으로 분류하면 안됨!

#### 3️⃣ **Recall (재현율/민감도)** - "양성 탐지 능력"
```python
from sklearn.metrics import recall_score
recall = recall_score(y_true, y_pred)
```
$$Recall = \frac{TP}{TP + FN}$$

- **실제 양성 중 양성으로 예측한 비율**
- **언제 중요?** → FN을 줄여야 할 때
  - 🏥 **암환자 진단**: 환자를 놓치면 안됨! (생명과 직결)
  - 🚨 **사기 거래 탐지**: 사기를 놓치면 큰 손실!

#### 4️⃣ **F1 Score** - "Precision과 Recall의 조화평균"
```python
from sklearn.metrics import f1_score
f1 = f1_score(y_true, y_pred)
```
$$F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}$$

- Precision과 Recall이 균형잡혀 있을수록 높은 점수
- **불균형 데이터에서 Accuracy 대신 사용!**

### 🎯 실전 의사결정 가이드

```python
# 상황별 중요한 지표 선택
if 문제_유형 == "암환자_진단":
    중요_지표 = "Recall"  # 환자를 놓치면 안됨!
    
elif 문제_유형 == "스팸메일_필터":
    중요_지표 = "Precision"  # 정상메일을 스팸으로 하면 안됨!
    
elif 문제_유형 == "균형잡힌_분류":
    중요_지표 = "F1_Score"  # 둘 다 중요!
```

### 🎨 PR Curve & ROC Curve (고급 평가)

#### **PR Curve (Precision-Recall Curve)**
```python
from sklearn.metrics import precision_recall_curve, average_precision_score

precision, recall, thresholds = precision_recall_curve(y_true, y_proba)
ap_score = average_precision_score(y_true, y_proba)
```
- **언제 사용?** → 양성 클래스가 중요한 불균형 데이터
- AP Score 높을수록 좋음 (1에 가까울수록)

#### **ROC Curve (ROC-AUC)**
```python
from sklearn.metrics import roc_curve, roc_auc_score

fpr, tpr, thresholds = roc_curve(y_true, y_proba)
auc_score = roc_auc_score(y_true, y_proba)
```
- **언제 사용?** → 양성/음성 탐지가 모두 중요한 경우
- **AUC Score 기준:**
  - 0.9~1.0: 매우 좋음 ⭐⭐⭐
  - 0.8~0.9: 좋음 ⭐⭐
  - 0.7~0.8: 괜찮음 ⭐
  - 0.6~0.7: 개선 필요
  - 0.5~0.6: 나쁨

### 🎚️ Threshold (임계값) 조정 - 실전 필수 기술!

```python
# 기본: 0.5 임계값
y_pred = (y_proba >= 0.5).astype(int)

# Recall 높이기: 임계값 낮추기 (암환자 진단)
y_pred = (y_proba >= 0.3).astype(int)  # 더 많이 양성으로 예측

# Precision 높이기: 임계값 높이기 (스팸메일)
y_pred = (y_proba >= 0.7).astype(int)  # 확실한 것만 양성으로
```

**⚠️ Trade-off 관계:**
- 임계값 ↓ → Recall ↑, Precision ↓
- 임계값 ↑ → Recall ↓, Precision ↑

## 📐 4. 회귀(Regression) 평가지표

### 🔥 핵심 3대 지표

#### 1️⃣ **MSE (Mean Squared Error)**
```python
from sklearn.metrics import mean_squared_error
mse = mean_squared_error(y_true, y_pred)
```
$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y_i})^2$$

- 오차의 제곱 평균
- **단점:** 제곱이라 해석이 어려움

#### 2️⃣ **RMSE (Root Mean Squared Error)** ⭐ 가장 많이 사용!
```python
from sklearn.metrics import root_mean_squared_error
rmse = root_mean_squared_error(y_true, y_pred)
# 또는
rmse = np.sqrt(mse)
```
$$RMSE = \sqrt{MSE}$$

- **실제 오차와 같은 단위!** (해석 용이)
- 예: 집값 예측 → RMSE = 1000만원 (평균 1000만원 차이)

#### 3️⃣ **R² (결정계수)** ⭐ 모델 설명력!
```python
from sklearn.metrics import r2_score
r2 = r2_score(y_true, y_pred)
```
$$R^2 = \frac{\sum(\hat{y_i}-\bar{y})^2}{\sum(y_i - \bar{y})^2}$$

- Feature들이 Target을 얼마나 설명하는가?
- **0~1 사이 값**, 1에 가까울수록 좋음
- **0.7 이상이면 좋은 모델!**
